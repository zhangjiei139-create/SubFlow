# 依赖与公开前检查

## 外部组件

主要组件包括 FFmpeg/ffprobe、MKVToolNix、ffsubsync、可选 alass、Ollama、Qwen 模型、Tesseract、pgsrip、Subtitle Edit seconv、RapidOCR/ONNX Runtime、OpenCC、PySide6/Qt、NumPy、PyAV、OpenCV、Pillow 和 pysrt。具体功能可能只需要其中一部分。

OpenSubtitles 和 SubDL 是在线服务，需要用户自己的 API Key；本仓库没有预置 Key。设备授权模块保留源码，但示例配置不连接授权服务。

不包含这些工具的二进制、模型权重或字体。项目没有为第三方组件重新授予许可；实际发布必须核对版本、构建方式、组件许可证和对应分发义务。
