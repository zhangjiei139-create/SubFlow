## 运行公开身份检查

安装 Python 依赖后，在仓库根目录运行：

```powershell
python -B -m unittest discover -s tests -p test_automatic_work_identity_independent.py
python -B -m unittest discover -s tests -p test_media_identity_context.py
python -B -m unittest discover -s tests -p test_online_feature_resolution.py
```

这些测试使用本地构造的元数据与模拟响应，不能代替真实字幕站准确率和延迟实测。其他测试可能需要 Windows Qt、FFmpeg、MKVToolNix、本机字体或已安装工具。整套 GUI 测试应分模块运行，避免 Qt 事件循环和应用实例交叉污染；不要把外部依赖缺失当作所有逻辑回归失败。

三份依赖真实 PGS 时序夹具的测试，以及专用安装器布局测试不纳入公开副本。工具二进制、模型和私人构建脚本不随仓库提供。字体相关测试使用 assets/subtitle-fonts 中的五款原样 OFL 字体，部分渲染/封装测试另需对应外部工具。
