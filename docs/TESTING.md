# 测试范围

公开副本保留 142 份测试/辅助 Python 文件，主要覆盖片名与身份、候选拒收、音轨参照、核听状态、翻译恢复、字幕样式和界面衔接。文件数不是测试用例数。

本次公开副本单独运行 8 个模块、123 项专项检查全部通过、无跳过，涵盖 96 项身份检查，以及随附字体、字体列表、详情呈现和进度清理。每个模块使用独立进程和私有配置目录，禁止真实网络，实际导入来自公开副本；未加载翻译模型或处理用户影片。该专项结果不冒充公开副本所有 142 份测试均已重跑。

## 正式版本证据

- 2.0.82 正式源码身份流程最终矩阵为 955 个不同方法（包含 55 项独立新增身份检查）；正式提升后另做 101 项相关复核，二者重叠，不重复相加。
- 构建程序和安装程序分别通过相同的 947 项桌面冻结回归，覆盖 76 个模块；业务代码来自实际 EXE/PYZ。另 8 项独立命令行与 11 项安装版本/布局检查单列。
- 8 个作品身份样本取得预期作品 ID，196 条自动下载前准入未混入别片。这是该样本的目录身份/候选筛选结果，并非字幕可用率、全片同步正确率或任意影片成功率。
- 不把内部真实影片、缓存或转写内容复制到公开仓库；未声称公开仓库已经在全新机器跑通所有检查。

## 运行公开身份检查

安装 Python 依赖后，在仓库根目录运行：

```powershell
python -B -m unittest discover -s tests -p test_automatic_work_identity_independent.py
python -B -m unittest discover -s tests -p test_media_identity_context.py
python -B -m unittest discover -s tests -p test_online_feature_resolution.py
```

这些测试使用本地构造的元数据与模拟响应，不能代替真实字幕站准确率和延迟实测。其他测试可能需要 Windows Qt、FFmpeg、MKVToolNix、本机字体或已安装工具。整套 GUI 测试应分模块运行，避免 Qt 事件循环和应用实例交叉污染；不要把外部依赖缺失当作所有逻辑回归失败。

三份依赖真实 PGS 时序夹具的测试，以及专用安装器布局测试不纳入公开副本。工具二进制、模型和私人构建脚本不随仓库提供。字体相关测试使用 assets/subtitle-fonts 中的五款原样 OFL 字体，部分渲染/封装测试另需对应外部工具。
