# 公开源码同步规则

本目录是独立的公开源码副本，只通过白名单同步 2.0.82 已验收源码，没有导入开发目录的 Git 历史、备份或诊断目录。

- 同步正式 Python 业务代码、三份 QML 入口/界面、必要图标、installer 的 Python 辅助模块与测试。
- 使用关闭设备授权连接、无实际服务地址或密钥的示例配置；个人配置继续被忽略。
- 保留此前公开副本的四处个人工具发现路径清理、相对 FFmpeg/alass 路径及 Windows 已安装 UI 字体回退。三份测试的虚拟盘符改成中性示例，不改变业务策略。
- 本次加入产品使用的五款原样 SIL OFL 1.1 字体及完整版权/许可文件，见字体清单。忽略规则只对这五个确切 TTF 文件开放，不包含 Windows 字体或其他字体目录。
- 不纳入三份真实 PGS 时序夹具测试和依赖私人 Inno 构建布局的测试；其他测试的外部工具要求单列说明。
- 不上传影片、下载字幕、翻译缓存、模型、工具二进制、安装包、配置/授权、日志、历史截图、部署脚本或内部 AGENTS 历史。

这些适配只在公开副本中实施，不修改正式开发源码、已安装软件或用户数据。项目级许可证仍未选定，未新增项目 LICENSE；第三方文件按各自许可管理。
