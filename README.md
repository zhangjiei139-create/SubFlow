# SubFlow

如果你硬盘或 NAS 里存了一堆电影，想按自己的习惯整理字幕和音轨，不用一部一部手动折腾，SubFlow 就是干这个的。

它是 Windows 桌面工具，把找字幕、对时间轴、补语言、理音轨、重新封装串成批处理：电影拖进来，选择偏好，生成整理后的新文件。主视频保持原编码，字幕和音轨按需要调整。

**当前状态：** 这是一份早期源码快照。Windows 完整安装包已有，尚未随仓库发布；仓库当前只有源码，需要自己装。项目级许可证尚未选定。

## 功能

- 按你的偏好整理音轨和字幕语言，优先用可用的内嵌文本字幕。
- 缺少可用文本时，优先去 OpenSubtitles / SubDL 找英文字幕，候选需要通过身份、用途、完整性和时间轴检查。
- 字幕时间对不上时自动纠偏，先处理影片中间一段，证据不够再扩大范围。
- 保留图片字幕（PGS）的排版。图片字幕每条轨道独立核验，不直接套用文本字幕的时间偏移；另有 OCR 路线，质量看片源。
- 自动预检未通过时，可以人工核听前、中、后三段窗口，拖动整排字幕调整时间，不单独移动某一条。
- 本地翻译补齐缺少的语言；另有简繁转换和翻译缓存。翻译是本地模型跑的，质量不稳定，别指望太高。
- 按偏好保留原音轨、补充兼容音轨，或精简音轨数量。
- 最后用 MKVToolNix 重新封装，检查临时成品后再生成正式输出。

实话实说：时间模式匹配不代表每句台词内容都正确；本地模型可能漏译或误译，检查通过也不保证语义准确。剪辑版本不同或时间轴复杂的片子，可能需要换字幕或人工处理，也可能无法安全通过。

## 它不是什么

- 不是下载电影的工具，片子你自己准备。
- 不是专业字幕编辑器，逐句精修请用 Subtitle Edit。
- 主要做字幕和音轨整理，不做画质修复或视频压缩。

## 源码运行

需要 Windows + Python 3.12。源码装完不保证一次跑通，要有点折腾的心理准备。下面是开发启动方式，尚未完成全新电脑上的完整部署验证：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item product_config.example.json product_config.json
.\.venv\Scripts\python.exe -B qml_frontend\main.py
```

光装 Python 依赖还不够，按需要另外准备 FFmpeg/ffprobe、MKVToolNix、Ollama 和翻译模型。使用 OCR 还需要相应工具。首次模型下载、音频解码、翻译和大文件封装都可能花时间。

配置里的工具路径是示例，改成你自己电脑的。`product_config.json` 已加入 Git 忽略规则，不会因普通提交自动上传；不要强制提交个人配置。字幕服务需要你自己的 API Key。

`requirements.txt` 目前是开发环境基线，还不是完整锁定并验证过的依赖清单。具体依赖和发布前事项见 [依赖与公开前检查](docs/RELEASE_READINESS.md)。

## 仓库里有什么

有：源码、必要的界面图标、示例配置、说明和离线测试。

没有：电影、下载的字幕、翻译缓存、模型文件、工具二进制、安装包、个人配置或真实授权文件。部分依赖真实影片时间夹具和商业构建脚本的测试没有纳入此快照。

授权模块的代码还在仓库里，示例配置中是关掉的。真实授权服务地址已移除。正式社区版和发行策略还在整理。第三方组件按各自许可管理。
